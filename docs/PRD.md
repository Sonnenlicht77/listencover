# 摸鱼听书 listenCover · 产品需求文档（v5.1）

**版本**：v5.1  
**日期**：2026-09-15  
**核心变更**：国际化范围从「多语言」收窄为「仅中英双语」  
**产品形态**：纯网页端（H5 / PWA），不做小程序  
**核心定位**：单设备、零配置、本地优先的摸鱼听书工具  
**GitHub 仓库名**：`listencover`  
**部署方式**：Cloudflare Pages + GitHub，静态托管  
**开源策略**：主项目 MIT / Apache 2.0 开源  
**当前阶段**：保底层已跑通，TTS 接口预留，增强层暂不实现

## 1. 产品概述

### 1.1 一句话描述

一个看起来像音频播放器的网页，上传本地文档就能听；按 `~` 一键切换到伪装工作界面，保护隐私。

### 1.2 核心价值

- **零配置**：打开网页，上传文档，戴上耳机就能听。
- **本地优先**：正文、进度、设置全部存浏览器 IndexedDB / localStorage，不经过任何服务器。
- **隐蔽**：界面像音频播放器，老板键一键切换工作界面。
- **免费**：纯前端静态托管，零维护成本。
- **可扩展**：TTS 引擎采用接口抽象，保底层已实现，增强层预留接口。
- **双语支持**：中文 + 英文，覆盖主要用户群体。

### 1.3 目标用户

- 中文用户：上班期间想听小说、听文档的办公族。
- 英文用户：同样的摸鱼听书需求，英文小说、英文文档。

### 1.4 约束条件

- 个人开发者，零后端，零云存储。
- 不做小程序、不做在线书城、不存正文到服务器。
- TXT/MD 推荐 5MB / 硬上限 10MB；EPUB 硬上限 30MB 且解压后正文 ≤ 10MB。
- 段落数上限 5 万段。
- **国际化只做中英双语，不做日韩等其他语言。**
- 不做跨设备同步、WebDAV、导出/导入进度、二维码接续。
- TTS 保底层必须可用；增强层和备选层只留接口，不实现。

**技术要点**：

- 文案抽离为 key，运行时按语言加载。
- 语言优先级：`localStorage.lang` > 浏览器 `navigator.language` > 默认 `zh-CN`。
- 语言切换即时生效，无需刷新。
- 文档语言检测：统计中文字符占比，> 30% 判为中文，否则判为英文。

## 4. 明确不做

- 微信/支付宝等任何小程序。
- 在线书城、书源爬取、推荐、评论、社交。
- 用户正文上传云端。
- 自动切分或压缩文件。
- 独立「无障碍模式」认证。
- MVP 阶段统计/埋点/广告。
- 付费、订阅。
- 跨设备同步、WebDAV、导出/导入进度、二维码。
- **增强层和备选层 TTS 的具体实现（仅留接口）。**
- **日、韩、俄、阿拉伯语等更多语言；RTL；伪装模板本地化。**

## 5. 数据模型

**IndexedDB `docs` 对象仓库**：

```js
{
  id: string,
  name: string,
  ext: string,
  language: 'zh' | 'en',   // 检测到的文档主要语言
  paragraphs: string[],
  progress: { cur, at },
  addedAt: number
}
```

**localStorage `settings`**：

```js
{
  lang: 'zh-CN' | 'en',    // UI 语言
  rate, voiceName, theme,
  bossKey, bossPause, autoPauseOnBlur,
  ttsEngine: 'web-speech'
}
```
