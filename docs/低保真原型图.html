说明

低保真原型使用说明

覆盖范围：本原型覆盖 PRD v5.1 中 M1–M11 全部核心模块，按产品流程与逻辑平铺： 首次打开 → 导入 → 播放 → 伪装 → 设置 → 兼容性 → 数据管理 → 国际化。

国际化范围（本版本重点）： 只做中文 + 英文。涵盖 UI 文案、章节正则、编码检测、TTS 音色匹配四项。 不做日、韩、俄、阿拉伯语等其他语言，不做 RTL，不做伪装模板本地化。

TTS 三层策略： 保底层 Web Speech API——已实现，当前唯一可用引擎。 增强层 Kokoro / MOSS-TTS-Nano 和备选层 Edge TTS——仅留接口，UI 显示为「即将推出」锁定。

已覆盖的异常与边界状态： 空状态、首次引导、加载中、解析失败、删除确认、编码选择、 无输出设备、TTS 不可用、不支持浏览器横幅、EPUB 置灰、清除数据确认。

标注为「待确认」的位置： 取消解析后数据回滚、快捷键冲突处理文案。

未包含：正式视觉设计、动效、具体颜色、字体、图标细节、真实数据。 所有灰色块均为内容占位。已砍掉跨设备同步、WebDAV、导出/导入、二维码接续。 增强层和备选层 TTS 的具体实现不在当前范围内。
